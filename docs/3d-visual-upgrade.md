## 1. Окружение и рендер: убран внешний CDN из кадра

**Было:** `<Environment preset="city" environmentIntensity={0.38} />` — drei тянул `potsdamer_platz_1k.hdr`
(~1.5 МБ) с `raw.githack.com` внутри `<Suspense>`, без ErrorBoundary. Один заблокированный
запрос к третьей стороне = белый прямоугольник на сайте заказчика (подтверждено аудитом и
воспроизведено локально: `GET` к CDN вернул 0 байт, 3D не смонтировался).

**Стало:** окружение строится кодом из `Lightformer`-панелей (крупный мягкий софтбокс сверху,
холодная боковая панель, тёплый отскок снизу, слабое кольцо снизу) при `resolution={256} frames={1}`.
Ноль внешних запросов, ноль файлов, стабильный студийный свет.
Проверка: `performance.getEntriesByType('resource')` в собранной версии содержит только свой
origin и Google Fonts.

**ErrorBoundary.** Новый `Panel3D/SceneErrorBoundary.tsx` оборачивает `<Canvas>`: при любом сбое
3D (WebGL, компиляция шейдера, асинхронная ошибка загрузки) вместо белого экрана рендерится
2D-чертёж `FallbackBlueprint` + сообщение + кнопка «Повторить 3D». Проверено принудительным
сбоем в сборке (см. §5).

## 2. Режим «ТЕПЛО»: градиент стало видно

**Было:** в `thermal` коэффициент разлёта `k = 0` — панель стояла собранной, PIR (200 мм) был
скрыт за фасадом, и режим визуально не отличался от «СБОРКА».

**Стало:**
- `k = 0.45` в `thermal` — пирог раскрывается настолько, что видно все три слоя;
- фасад в `thermal` становится полупрозрачным (`opacity → 0.3`, `depthWrite` выключается) —
  градиент читается и через него;
- шейдер PIR переписан: четыре опорные точки цвета (−20 °C глубокий синий → −8 °C морозный →
  0 °C почти белый → +8 °C янтарный → +22 °C тёплый оранжевый) вместо трёх прежних, плюс
  тонкая яркая линия изотермы 0 °C (`uIsoPosition = 0.524` = 22 / (22 + 20) для канонических
  −20 / +22);
- камера в `thermal` уходит в более косой ракурс (baseX/Z 4.30 / 2.20 против 3.05 / 3.55),
  чтобы 390-мм пирог и градиент по толщине были видны с первого кадра;
- колауты слоёв в `thermal` не показываются (их роль берут три температурных тега); как только
  слой выбран — его колаут возвращается;
- теги температур разведены: на узких экранах показываются компактно (иконка + значение),
  на широких — с подписями; позиция внешних тегов адаптивна (`thermalTagX = 0.9 | 1.25`).

## 3. Модель, материалы, свет

- `envMapIntensity` задан явно для бетона фасада (0.55) и несущего слоя (0.5) — раньше они
  зависели от прежнего окружения; `bumpScale` снижен (0.035 → 0.022 и 0.038 → 0.026), чтобы
  микрорельеф не читался как «попкорн»;
- позиции крепежа Peikko, хотспотов и температурных тегов считаются от целевых координат
  кинематики, а не от мутирующего `ref` (`currentPos` удалён). Раньше после переключения режима
  связи могли оставаться в координатах предыдущего режима до следующего ре-рендера;
- `toneMappingExposure` 0.92 → 0.95, ambient 0.22 → 0.16 (свет теперь держит IBL);
- кадрирование: дефолтный ракурс отодвинут (3.05 / 1.25 / 3.55 против 2.8 / 1.3 / 3.4) — панель
  больше не упирается в края кадра;
- `dpr={[1, 1.75]}` — ограничение плотности пикселей на HiDPI/мобильных; `AdaptiveDpr` без
  `pixelated` (во время вращения картинка не «рассыпается» на квадраты).

## 4. Замеры (локальная сборка, Edge headless, RTX 2060 SUPER, D3D11)

| Метрика | До | После |
|---|---|---|
| Внешние запросы | `raw.githack.com` HDRI ~1.5 МБ | нет (только Google Fonts) |
| Внешний домен в критическом пути 3D | есть | нет |
| Бандл JS | 1 688 403 Б (473 КБ gzip) | 1 693 241 Б (475 КБ gzip) |
| Первый кадр 3D (готовность текстур) | ~1.7 c (тот же замер) | ~1.7 c |
| Наложения текста, режим ТЕПЛО 1600×900 | 3 (в т.ч. колаут × правый рельс 824 px²) | 2 (обе — нижняя полоса, см. §6) |
| Наложения текста, режим ТЕПЛО 390×844 | 4 (в т.ч. «512px Hi-Res» × «АНАТОМИЯ» 666 px²) | 3 (все три — нижняя полоса, см. §6) |

Проверка наложений — сканер из приложения A аудиторского отчёта (пары текстовых боксов > 250 px²).

## 5. Как воспроизвести проверку фолбэка

1. в `PanelModel.tsx` перед `return (` добавить `if (mode === 'thermal') throw new Error('smoke');`
2. `bun run build`, открыть виджет, переключить в «ТЕПЛО»;
3. ожидаемо: вместо сцены — плашка «3D НЕДОСТУПНО / ПОКАЗАН 2D-РАЗРЕЗ ПАНЕЛИ», 2D-чертёж
   с подписями слоёв и кнопка «Повторить 3D»; белого экрана нет;
4. убрать строку, пересобрать.
