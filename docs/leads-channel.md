# Куда уходят заявки ABG3D (t_f8e53c1c)

Дата: 18.09.2026. До этой задачи формы виджета честно отправляли `POST`, но адреса
приёма не существовало — заявки нигде не появлялись, а пользователь видел
«Отправка сейчас недоступна: канал заявок не настроен».

Теперь адрес есть: **`https://abg.hiborg-space.ru/api/leads`** — он прописан в
`.env.production` (переменная `VITE_LEADS_ENDPOINT`), т.е. попадает в production-сборку.
Рантайм-переопределение `window.ABG3D_LEADS_ENDPOINT` осталось и имеет приоритет —
нужно для встраивания виджета на сайте заказчика.

## Что происходит с заявкой

```
виджет (abg.hiborg-space.ru или сайт заказчика)
   │  POST /api/leads   (JSON, CORS *)
   ▼
nginx  (location /api/ → 127.0.0.1:8862)
   ▼
abg-leads  (systemd, чистый Python 3, без внешних зависимостей)
   ├─ honeypot заполнен         → отвечаем «ок», но НЕ сохраняем и никого не дёргаем
   ├─ контакт/вид невалидны     → 422 (виджет показывает ошибку поля)
   ├─ больше 10 заявок с IP за 10 минут → 429
   ├─ SQLite  /root/abg-leads/data/leads.db   ← основное хранилище
   ├─ CSV     /root/abg-leads/data/leads.csv  ← открывается в Excel
   └─ уведомление в Telegram (Саша) в фоне: ответ виджету не ждёт Telegram
        └─ опционально: вебхук в CRM (amoCRM/Bitrix) и/или письмо по SMTP
```

Ответ виджету — `200 {"ok": true, "id": "<12 hex>"}`; виджет показывает успех только
по 2xx и подставляет id в консоль/лог интегратора. Заявка считается принятой только
после записи в SQLite: если уведомление упало, заявка всё равно на месте
(колонки `notify_telegram` / `notify_webhook` / `notify_email` содержат `ok` / `skip` / `error: …`).

## Чтение заявок

| Способ | Как |
|---|---|
| Быстро посмотреть | `GET https://abg.hiborg-space.ru/api/leads?limit=50`, заголовок `X-Admin-Token: <токен>` |
| Выгрузить в таблицу | `GET …/api/leads.csv?limit=500` с тем же заголовком |
| Прямо в базе | `ssh root@89.125.121.189`, `sqlite3 /root/abg-leads/data/leads.db 'select * from leads'` |
| Живость канала | `GET /api/healthz` (без токена) — число заявок и какие уведомления настроены |

Токен администрирования лежит только в `/root/abg-leads/.env` (`ABG_LEADS_ADMIN_TOKEN`,
файл 600), сгенерирован на сервере и в репозиторий/переписку не попадает.
Без токена `GET /leads` отвечает 401 — заявки не светятся всему интернету.

## Смена канала доставки (решение заказчика)

Приёмник ничего не знает про конкретный канал — он сохраняет заявку всегда, а доставку
включают переменными в `/root/abg-leads/.env` и `systemctl restart abg-leads`:

| Канал | Что задать |
|---|---|
| Telegram (работает сейчас) | `ABG_LEADS_TG_TOKEN`, `ABG_LEADS_TG_CHAT`; если не заданы — берутся `SHTAB_BOT_TOKEN`/`SHTAB_CHAT_ID` из `/root/shtab/.env` |
| amoCRM / Bitrix / любой CRM | `ABG_LEADS_WEBHOOK=https://…` — туда уходит тот же JSON, что прислал виджет |
| Почта ABG | `ABG_LEADS_SMTP_HOST/PORT/USER/PASS/TO` |
| Ничего не настраивать | заявки всё равно копятся в SQLite+CSV и в Telegram |

Бэкап заявок: `/root/abg-leads/backup_leads.py`, cron 04:10, копии в `/root/backups/abg-leads/`
(SQLite backup API + `integrity_check`, хранится 14 копий).

## Что осталось решением заказчика

Технически канал открыт и проверен end-to-end, заявки доходят до Саши в Telegram.
Открытым остаётся **организационный** вопрос: какой канал нужен самому заводу (ящик ABG,
их CRM, отдельный чат с менеджером). Включается одной строкой в `.env` без правок кода
и без пересборки виджета — см. таблицу выше.

## Проверено

- самотест приёмника на VPS (`selftest.py`, 12 проверок): валидная заявка → 200 + id,
  запись в SQLite и CSV, уведомление Telegram `ok`, пустой/кривой контакт → 422,
  чужой `kind` → 422, honeypot → 200 без записи, не-JSON → 400, 11-я заявка с одного IP → 429,
  `GET /leads` без токена → 401;
- `https://abg.hiborg-space.ru/api/healthz` отвечает `{"ok":true}` через nginx,
  `POST /api/leads` с внешнего адреса проходит (CORS: `Access-Control-Allow-Origin` для
  предполётного `OPTIONS`);
- живой виджет на `abg.hiborg-space.ru` после деплоя сборки с `VITE_LEADS_ENDPOINT`
  отправляет заявку, она появляется в базе с `notify_telegram=ok`.
